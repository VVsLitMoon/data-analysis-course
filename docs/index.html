VS Code：“讲义Markdown”中有逐节文本，“代码示例”中有 .sql、.py 和 Notebook。Notebook 先执行初始化单元。

数据：每次运行都恢复六张模拟电商数据表；一次代码区中的多条语句连续执行。SQL 用 MySQL 8.0；Python 预置同名 DataFrame，需用 print 显示结果。

运行环境：仅在本机运行自己的学习代码，不是供陌生用户使用的安全沙箱。不要把本地端口发布到公网。网页不会上传你的代码和笔记。

关闭：关闭启动窗口或点击下面按钮停止本地服务。只关浏览器页面不会停止程序；关闭前可导出学习记录。
