不是视频，不是文档站，是一个**能执行的教程**。

## 为什么在本地跑，而不是做成网课

**SQL 必须是真的 MySQL。** 窗口函数的帧定义、索引与 `EXPLAIN`、事务隔离级别，用 SQLite 模拟会学出错的肌肉记忆。这个项目直接起一个独立的 MySQL 8 实例（`127.0.0.1:33318`），每次运行前恢复教学数据。

**代码不出本机。** 执行引擎在本地子进程里，不上传任何代码。

代价是安装门槛：需要本机有 Python 和 MySQL。所以讲义做了降级设计 —— **没装 MySQL 也能读完全部课程、跑全部 Python 课**，只有 SQL 的运行按钮会提示环境缺失。

## 快速开始

前置：Python 3.10+；MySQL 8.0（只影响 SQL 课的「运行」按钮）。

```bash
pip install -r requirements.txt
python launch.py
```

浏览器会打开 `http://127.0.0.1:8766`。Windows 也可以直接双击 `启动讲义.cmd`。

MySQL 不在默认位置时，用环境变量指定 bin 目录：

```bash
set MYSQL_BIN=D:\mysql\bin        # Windows
export MYSQL_BIN=/usr/local/mysql/bin   # macOS / Linux
```

端口被占用时，启动器会先探测该端口是不是本讲义实例：是则直接复用，不是则报错退出，不会去动别人的进程。

## 三个设计取舍

**1. 每次运行都重置教学数据。**
学生改坏数据是常态。与其教人 `ROLLBACK`，不如让每次点「运行」都回到干净状态 —— 这样敢乱改。代价是跨运行的数据修改不保留，讲义里明说了。

**2. Python 在独立子进程里执行，带 AST 白名单。**
不是安全沙箱 —— 这点写在限制里，没有假装。白名单只放行数学/统计/数据分析模块，禁止文件与网络操作，目的是**防止误操作**，不是防御恶意代码。

**3. 静态文件走白名单。**
服务端只对外提供 `index.html`、`app.js`、`style.css`、`lessons.js`、`favicon.svg` 五个文件，源码和运行数据取不到。

## 复现与自检

课程内容由 `build_book.py` 生成，改课程只改这一个文件：

```bash
python 程序/build_book.py      # 重新生成 lessons.js / curriculum.json / 讲义Markdown / 代码示例
python 程序/validate_book.py   # 检查静态白名单与示例
```

运行时会生成 `runtime/`（数据库文件与日志），已在 `.gitignore` 里排除。

## 已知限制

- **不是安全沙箱**：本地单用户使用，不要把这个服务暴露到公网
- **没有自动判题**：自测题知道答案，但用户改写的代码不会自动评分，`执行成功` 只代表跑通了
- **只在 Windows + MySQL 8.0 上验证过**，其他平台理论上可用（服务只用标准库），但没实测
- 参数实验的公式有明确近似假设（双侧、等量分组、大样本），不能套到集群实验或序贯检验上
