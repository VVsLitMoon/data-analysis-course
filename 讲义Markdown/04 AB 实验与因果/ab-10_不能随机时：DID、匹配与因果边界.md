# ab-10 · 不能随机时：DID、匹配与因果边界

## 前后对比为什么不够
活动后销售上升可能源于节假日、竞争变化或用户组成。反事实是“同一对象如果没接受处理会怎样”，现实看不到，需要设计或假设帮助识别。
## DID 的核心计算
双重差分 = (实验群后-前) - (对照群后-前)。关键假设包括无处理时趋势平行、没有差异化同期冲击等；实验前趋势相近是有用证据，但不能证明未来平行。
## 其他方法知道在解决什么
匹配/倾向得分尽量平衡已观测混杂，无法保证消除未观测混杂；RDD 利用阈值附近的可比性，需要不能精确操纵等条件；工具变量需要相关性和排除限制等强假设。别把方法名称当因果证明。

## 可运行例子

```python
treat_before,treat_after = 100,130
control_before,control_after = 80,95
did = (treat_after-treat_before)-(control_after-control_before)
print("DID 估计：",did)
```

## 自测

DID 最核心的识别假设之一是？

1. 两组水平必须完全相等
2. 样本大就无需假设
3. 无处理时两组趋势平行

<details><summary>答案与解释</summary>

答案：3。差分消除固定水平差异，但不能自动消除不同趋势。
