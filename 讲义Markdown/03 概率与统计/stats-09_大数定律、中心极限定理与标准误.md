# stats-09 · 大数定律、中心极限定理与标准误

## 大数定律告诉你平均趋向哪里
满足条件时，独立同分布样本的平均随着样本量增加接近期望，但单次样本不保证单调更接近，也不承诺下一次就补偿前面的偏差。
## 中心极限定理告诉你均值怎么波动
在合适条件下，标准化后的样本均值分布趋近正态；这不表示原始金额分布变成正态。重尾、相关、极小样本可能需要额外处理。
## 标准差与标准误
标准差描述个体差异；均值的标准误 SE≈s/√n 描述估计的不确定性。样本量扩大 4 倍，标准误约减半。相关数据的有效样本量比行数小，不能把每次点击都当独立用户。

## 可运行例子

```python
import numpy as np
rng = np.random.default_rng(42)
for n in [10, 100, 1000]:
    means = rng.exponential(scale=10, size=(1000, n)).mean(axis=1)
    print(n, "均值的标准差：", round(means.std(ddof=1), 3), "理论近似：", round(10/np.sqrt(n), 3))
```
