# stats-07 · 伯努利、二项与超几何分布

## 一次成败与多次成败
一次是否购买可用伯努利分布：成功概率 p，期望 p，方差 p(1-p)。n 次独立且成功概率相同的试验，成功次数用二项分布，期望 np，方差 np(1-p)。
## 二项公式怎么理解
恰好 k 次成功：C(n,k)×p^k×(1-p)^(n-k)。组合数数成功位置，其余两项给一种顺序的概率。用户彼此有干扰或成功概率差异大时，简单二项模型可能不合适。
## 不放回抽取
有限总体中有固定成功数，不放回抽样的成功次数用超几何分布。抽后总体组成改变，不能机械把每次概率相乘成同一个 p。

## 可运行例子

```python
from scipy.stats import binom, hypergeom
print("10 次、p=0.2，恰好 2 次：", binom.pmf(2, 10, 0.2))
print("至少 2 次：", binom.sf(1, 10, 0.2))
print("10 个中 3 个红球，抽 2 个都红：", hypergeom.pmf(2, 10, 3, 2))
```

## 自测

二项分布通常要求？

1. 必须不放回
2. 结果可以有任意连续金额
3. 固定次数、独立、相同成功概率
