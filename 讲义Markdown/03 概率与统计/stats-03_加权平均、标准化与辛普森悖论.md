# stats-03 · 加权平均、标准化与辛普森悖论

## 整体比例不能随便平均
A 渠道 10 人里 5 人购买，B 渠道 100 人里 10 人购买。整体是 15/110，不是 (50%+10%)/2。应按分母加权：Σ(分组比例×分组人数)/总人数。
## 每组变好，整体也可能变差
当流量从高转化群体转向低转化群体，即便各群体转化率上升，整体也可能下降。这是辛普森悖论的一种情形。先看分层表现，再看结构占比变化。
## 标准化怎样帮助比较
固定同一套人群权重，比较两期的分层转化率，可以区分结构变化与组内变化。z-score=(x-均值)/标准差 用来衡量离均值几个标准差，但不会自动把任意分布变成正态。

## 可运行例子

```python
buyers = [5, 10]
visitors = [10, 100]
rates = [buyers[i] / visitors[i] for i in range(2)]
print("错误的等权平均：", sum(rates) / 2)
print("整体转化率：", sum(buyers) / sum(visitors))
```

## 自测

合并两组转化率时应该？

1. 合并分子分母，或按分母加权
2. 永远直接平均比例
3. 选较大比例
